## 1. はじめに知っておくべきこと

### スキャンした PDF は「画像」です

紙をスキャンした PDF には文字データが入っていません。AI は画像として見て読み取ります。つまり **AI の読み取り精度は、スキャン画質でほぼ決まります**。

- **推奨: 300dpi 以上、グレースケール**(白黒2値は薄い鉛筆が消えるため避ける)
- 鉛筆書きは濃く書くよう事前に指導すると、精度が目に見えて上がります
- 傾き・影・折れ目は読み取り精度を下げます

### PDF に保護がかかっていることがある

コピー機や複合機で作成した PDF には保護フラグが付く場合があり、一部のツールが「パスワード保護」として拒否することがあります。この場合も画像変換自体は可能なので、AI に「保護フラグで読めない場合は画像に変換してから読んで」と伝えておくと、AI が自動で回避します。

### 名前・番号欄はミスが起きやすい

実際の運用では、**番号が空欄、番号と名前の不一致、同じ番号が2人**といったことが普通に起こります。AI に「不一致は勝手に補正せず報告して」と明示しておくことが重要です。

### 最終判断は必ず人が行ってください

AI の採点は「たたき台」です。特に以下は人の目で確認してください。

- 判読に迷った答案(AI に「確信度が低い箇所」を報告させる)
- 評価が極端に低い答案(読み取りミスの可能性)
- 成績に直結する最終得点

## 2. 基本プロンプト(そのままコピーして使う)

> 以下の `【 】` の部分を、自分の状況に合わせて書き換えてください。

```markdown
# 依頼内容

添付(または指定フォルダ内)の PDF に収録された、生徒の手書き英作文を採点してください。

## ファイル情報

- ファイル: 【C:\Users\xxx\Desktop\自動採点\英作文data.pdf】
- 内容: 1ページにつき生徒1名分の答案
- 形式: 紙の答案をスキャンした画像PDF(文字データなし・手書き)
- 出題: 各ページ上部に印刷されています

## 事前の注意

- この PDF は保護フラグが付いている可能性があります。ツールが「パスワード保護」で
  読めない場合は、各ページを画像(PNG・解像度2倍以上)に変換してから読み取ってください。
- ヘッダー(クラス・番号・氏名)が読みにくい場合は、その部分だけ切り出して拡大し、
  再確認してください。推測で埋めないでください。

## 作業手順

### ステップ1:読み取り
1. 各ページから「クラス・出席番号・氏名」を読み取る
2. 生徒が書いた英文を一字一句そのまま転記する
   - **綴りの誤りを勝手に直さないこと**(採点対象のため)
   - 判読できない語は [判読不能] と記し、どのページの何行目かを報告する
3. 語数を数える(ピリオド・カンマは数えない)

### ステップ2:採点(30点満点)

以下の4観点で採点してください。

【① 内容 ― 10点】問いに答えているか。英語の巧拙は見ない。
- 9-10: 立場明確+理由2つ+それぞれに具体例や説明がある
- 7-8: 立場明確+理由2つあるが、展開が薄い理由がある
- 5-6: 理由が1つのみ/理由2つが実質同じ内容/立場があいまい
- 3-4: 途中で終わっている/理由が主張を支えていない
- 0-2: 問いに答えていない

【② 構成 ― 5点】意見→理由→結論の型と、つなぎ語の適切さ。
- 5: 型が完全。First/Second/Therefore 等が適切
- 3-4: 型はあるが結論がない/つなぎ語が単調
- 1-2: 文の羅列で構成が見えない
- 0: 構成なし

【③ 語彙 ― 7点】正しさより「適切さと幅」。
- 6-7: 話題に合った語彙を的確に選べている。軽微な綴りミスは許容
- 4-5: 基本語彙で用は足りるが幅がない。同語の繰り返しが多い
- 2-3: 語の選択ミスで意味が誤解される箇所がある
- 0-1: 語彙不足で意図がほぼ伝わらない

【④ 文法 ― 8点】誤りの「数」ではなく「重さ」で見る。
- 7-8: 意味が通じなくなる誤り(グローバルエラー)なし。冠詞・三単現等の軽微な誤りが数か所
- 5-6: グローバルエラーが1つ程度。全体は問題なく読める
- 3-4: グローバルエラーが複数あり、読み手の推測が必要
- 1-2: 大半の文に構造的問題があり、解読に苦労する
- 0: 英文として成立していない

### 採点の原則(必ず守ること)

1. **加点主義で採点する。** 「誤りがないか」ではなく「何ができたか」を数える。
   短く安全にまとめた答案より、長く挑戦して誤りの出た答案が高くなるようにする。
2. **ダブルカウント禁止。** 1つの誤りは1観点でのみ減点する。
   綴りの誤り=語彙のみ、文構造の誤り=文法のみ。
3. **同じ誤りの繰り返しは1回として数える。**
4. **グローバルエラー(意味が通じない誤り)を重く、ローカルエラー(通じるが不正確)を軽く扱う。**
5. **語数による機械的な減点はしない。** 短さは「内容の展開不足」として内容点に反映させる。
   ※生徒に語数の目安を事前告知している場合のみ、内容点から減点してよい。

### ステップ3:評価文の作成

生徒一人ひとりに、150〜250字程度の評価文を書いてください。以下の順序を守ること。

1. **できていることを具体的に挙げる**(必ず最初に、必ず具体的に。「よく書けています」のような
   一般論は書かない。その生徒の答案から実際の表現を引用して褒める)
2. **最も優先して直すべき点を1〜2点だけ挙げる**(全部列挙しない。生徒が読まなくなるため)
3. **正しい表現を提示する**(「〇〇が誤り」で終わらせず、「〇〇ではなく△△」と書く)

文体は、生徒本人が読むことを想定した「です・ます」調にしてください。

## 出力形式

以下の3つを出力してください。

1. **得点一覧表**:番号・氏名・語数・観点別得点・合計点
2. **個票**:生徒ごとに「転記した英文 → 観点別得点 → 評価文」
3. **クラス全体の講評**:観点別平均と、次回の指導ポイント

## 必ず報告してほしいこと

- 番号・氏名の欠落や不一致(勝手に補正しないこと)
- 同じ番号・氏名が複数ページに現れた場合
- 判読に自信がない箇所(ページ番号と該当箇所を明示)
- 白紙・途中終了の答案

## 保存先

結果は 【C:\Users\xxx\Desktop\自動採点\】 に Markdown ファイルで保存してください。
```

## 4. 部品として使える追加指示

必要に応じて、基本プロンプトの末尾に足してください。

### 前回との比較をしたいとき

```markdown
前回の採点結果ファイル 【英作文_採点結果_1学期.md】 と比較し、
生徒ごとに「観点別の伸び/落ち」を +2、-1 のように示してください。
特に伸びた生徒・落ちた生徒を3名ずつ挙げ、その要因を分析してください。
```

### Excel で成績処理したいとき

```markdown
採点結果を Excel ファイル(.xlsx)としても出力してください。
1行1生徒、列は「番号・氏名・語数・内容・構成・語彙・文法・合計・評語」とし、
合計点の降順で並べ、合計点のセルには点数帯に応じた色分け(条件付き書式)を付けてください。
```

### 生徒に返す個票を印刷したいとき

```markdown
生徒に返却する個票を、1人1ページの PDF として作成してください。
各ページに「氏名・観点別得点のレーダーチャート・合計点・評価文・次回への具体的な目標1つ」
を配置してください。他の生徒の情報や順位は載せないでください。
```

### 採点の甘辛を調整したいとき

```markdown
今回は【1学期の中間テスト/入試演習】としての採点です。
基準を【やや緩めに(定着途上のため励ましを重視)/厳しめに(入試水準で)】適用してください。
ただし観点の配点と原則(加点主義・ダブルカウント禁止)は変更しないでください。
```

### 誤りの傾向をクラス指導に活かしたいとき

```markdown
全生徒の誤りを集計し、以下を出してください。
- 2名以上が共通して間違えた項目(頻度順)
- それぞれについて「なぜ間違えるのか」の推定と、授業での指導案(5分程度で扱える形で)
```

## 5. うまくいかないときの対処

| 症状 | 原因 | 対処 |
|:---|:---|:---|
| 「パスワード保護で読めない」と言われる | 複合機が付けた保護フラグ | 「画像に変換してから読んで」と指示する |
| 文字が読めない・誤読が多い | スキャン解像度不足、鉛筆が薄い | 300dpi以上で再スキャン。AI に「解像度2倍以上で画像化して」と指示 |
| 番号や氏名を間違える | ヘッダーが小さく手書き | 「ヘッダー部分を切り出して拡大してから読んで」と指示 |
| 綴りミスを直して転記してしまう | AI が親切に補正する癖 | 「一字一句そのまま。綴りの誤りを直さないこと」を**太字で**明示 |
| 全員の点が似た値になる | 基準の適用が曖昧 | 各観点で「何点にしたか、その根拠は答案のどの部分か」を書かせる |
| 評価文がどれも同じ内容 | 一般論で書いている | 「必ず本人の答案から実際の表現を引用して褒めること」を追加 |
| 減点が厳しすぎる | 減点主義に流れている | 「加点主義」「ダブルカウント禁止」を再度強調し、採り直させる |
| ページ数と生徒数が合わない | 白紙・重複・スキャン漏れ | 「総ページ数と採点した人数を最初に報告して」と指示 |

## 6. プロンプト作成の考え方

このプロンプトが長いのには理由があります。短いプロンプトでも AI は採点しますが、その場合 AI は**自分の判断で基準を決めます**。同じ答案でも実行するたびに点が変わり、成績処理には使えません。

逆に言えば、**長く書くべきなのは「基準」の部分だけ**です。押さえるべきは次の5つです。

**① 点数の刻みごとに、具体的な状態を書く**
「文法が正確なら高得点」では AI ごとに解釈が割れます。「グローバルエラーなし+軽微な誤りが数か所 = 7-8点」まで書くと、実行するたびに同じ点になります。

**② 「やってはいけないこと」を明示する**
AI は放っておくと親切に振る舞います。綴りを直して転記する、空欄の番号を推測で埋める、といったことは、指示がなければ起こります。**採点業務では、この「親切さ」が事故になります。**

**③ 採点の哲学を最初に書く**
「加点主義」「ダブルカウント禁止」「グローバル/ローカルエラーの区別」。この3つを書くかどうかで、同じ配点表でも結果が5点以上変わります。特に**加点主義を書かないと、AI はほぼ確実に減点主義で採点します**。

**④ 出力の形を指定する**
表なのか文章なのか、どこに保存するのか。指定しないと毎回違う形式で返ってきて、結局手作業が発生します。

**⑤ 例外の報告を求める**
番号の欠落、重複、判読不能。これらは必ず起こると想定して、「勝手に処理せず報告せよ」と書いておきます。

そして最後に、**採点基準そのものは AI に作らせず、教員が決めてください。** AI は基準を正確に適用する道具としては非常に有能ですが、「このクラスの生徒に今どの観点を重く見るべきか」は、生徒を見ている人にしか判断できません。

# 数学小テスト：採点・個票PDF・得点記録を一括で行うプロンプト

以下のPDFは、高校数学の小テスト答案です。答案を読み取り、採点から返却用個票の作成、Googleスプレッドシートへの得点記録までを一連で行ってください。

## 前提と注意

- 対象は中学生・高校生向けの返却資料です。説明は正確で、必要に応じて用語をかみ砕いて書いてください。
- 答案の氏名・番号・得点などは、この作業に必要な範囲でのみ扱ってください。外部の不特定サービスへ個人情報を転載しないでください。
- 手書きの判読が不確かな箇所、設問文・配点・模範解答が不足している箇所は、推測して確定せず、該当する生徒・設問・判読候補を示して確認を求めてください。
- 採点結果と生成したPDFは、必ず目視または内容検証を行ってから出力してください。AIの採点は補助であり、成績の最終決定は教員が行います。

## 入力

- 答案PDF：このメッセージに添付したPDF
- 採点基準・配点・正答：このメッセージに続けて示す内容を最優先する。示されていない場合は、PDF内の設問から正答を計算・確認し、採点前に簡潔に採点基準案を示す。
- クラス名：`2年X組`
- 得点記録先のGoogleスプレッドシート：`2年X組_数学Ⅱ小テスト`
  - 既存のスプレッドシートがある場合は、そのファイルを編集する。
  - 存在しない場合は、同名のGoogleスプレッドシートを新規作成する。

## 作業手順

1. PDFをページごとに読み取り、各生徒の「組・番号・名前」と、各設問の最終解答を整理する。
2. 設問ごと・採点欄ごとに採点する。途中式がある場合は、指定された採点基準に従って部分点を判断する。指定がない場合は、原則として最終解答を中心に採点し、部分点の扱いは明示する。
3. 生徒ごとに、次を作成する。
   - 得点（満点と内訳を含む）
   - できていること
   - 間違った問題の確認
     - 誤答箇所と配点
     - 正解
     - 必要な知識・解き方の要点
   - 「次の問題を解きなさい」という見出しの下に、間違った内容に対応する類題をまとめて掲載する。
   - 類題の下に、実際に計算・記述できる大きさの解答欄を設ける。
   - 全問正解の場合は、発展問題を1題載せ、同様に解答欄を設ける。
4. 生徒一人につきA4・1ページの返却用「個票PDF」を作成する。
   - 見出しには、科目・テスト名・`2年X組`・番号・名前を明記する。
   - 文字切れ、表のはみ出し、数式の崩れがないことを確認する。
   - 個別PDFに加え、全員分を1つに結合したPDFも作成する。
5. 教員確認用に、番号・名前・得点・得点内訳・評価の要点を掲載した採点一覧PDFを作成する。
6. Googleスプレッドシート `2年X組_数学Ⅱ小テスト` に得点を記録する。
   - シート名は、テスト名が明確に分かる名称（例：`数学Ⅱ小テスト_1回目`）にする。指定がある場合はその名称を使う。
   - A列：`番号`
   - B列：`名前`
   - C列：今回の回数名（例：`1回目`）
   - 生徒ごとの得点を、番号順に数値として入力する。
   - 最終行に `平均点` を置き、得点列には平均を求める数式を設定する。
   - 既存シートに追記する場合は、既存の値・数式・書式を壊さない。対象列と対象行を確認してから書き込む。
   - 入力後、番号・名前・得点・平均点の数式を読み直して検証する。
7. 最後に、次を簡潔に報告する。
   - 採点した生徒数
   - 生徒ごとの得点
   - 作成した採点一覧PDF、個票PDF（全員分）、Googleスプレッドシートへのリンク
   - 判読困難箇所や、教員による確認が必要な採点があれば、その内容

## 出力先

- PDFは、作業フォルダー内の `output` または指定された出力フォルダーに保存する。
- 同じ名前の出力フォルダーが既にある場合は、既存ファイルを不用意に上書きせず、日時や回数を付けた新しいフォルダーを使う。

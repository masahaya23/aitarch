ゲーム概要

指数法則(累乗の計算・負の指数・累乗根・有理数指数)を、5択から答えを選ぶクイズ形式で練習するアプリです。 自分のユーザー番号(G01〜G40)を選んでプレイすると、20問中の正解数が自動で記録されます。 間違えた問題は、指数法則に基づいた途中式の解説が表示されるので、その場で理解しながら進められます。 16問以上の正解で「合格」です。合格するまで、何度でも挑戦できます。

対象 高校数学(指数の拡張 / 数学II)
出題数 1プレイ20問(4ステージ×5問)
合格基準 20問中16問以上正解
対象ユーザー G01 〜 G40(起動時に選択)
作成 HTML / CSS / JavaScript

出題ステージ

ステージ1

指数の基本計算

積・商・累乗の指数法則(正の指数)

ステージ2

負の指数・0乗

a⁻ⁿ = 1/aⁿ, a⁰ = 1 を含む計算

ステージ3

累乗根の計算

n乗根の値・積と商の簡約

ステージ4

有理数指数

a^(m/n) の変換・複合計算

操作方法

  • 起動画面でユーザー番号(G01〜G40)を選んで「ゲームをはじめる」
  • 表示された問題に対して、5つの答えの中からクリックで1つ選ぶ
  • 正解なら「✓ 正解！」、不正解なら「✗ 不正解」と表示され、不正解の場合は指数法則に基づいた途中式の解説が表示される
  • 「次の問題 →」ボタンを押して次に進む
  • 20問終了後、結果画面にスコアと合格判定・ステージ別の正解内訳が表示される
  • 不合格でも何度でも再挑戦できる。すべての結果は記録される
